Party game — Insan Hayawan Jamad

One letter. Five answers. Before time runs out.

The game we grew up on, now online: write a person, animal, thing, plant and country that all start with the same letter, with friends on your phones and the big screen.

How a round works

Join, write, mark, top the board.

Scoring

The red pen decides.

When time is up, everyone marks their own sheet. Marks appear live on the big screen so the room agrees before the next round.

Disagree? Any player can dispute an answer. The host accepts or rejects it, and the host has the final say.
