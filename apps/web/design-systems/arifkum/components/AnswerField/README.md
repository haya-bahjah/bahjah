# AnswerField

The phone's writing card, then the yellow sticker that replaces it once the answer is sent.

- The field is a 3px pink card with `--kyb-r-md` corners, a hard offset shadow, a pixel label, a borderless 19px/600 input and an ink-40 hint. On focus it adds a pink glow ring.
- 280 characters at most. Answers are private until the reveal.
- **Locked** (`kyb-locked`): a yellow fill with 3px ink outline and hard shadow, display 17px uppercase. The player can't change the answer once it's sent.
