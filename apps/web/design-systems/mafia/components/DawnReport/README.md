# DawnReport

The morning announcement, read together off the big screen and moved on from by every living player.

Three outcomes:
1. **Someone died** — the victim on a face-down card (250px, dot grid, faint red glow), their token at `--lg --dead`, name in `victim` type, *ROLE UNKNOWN*, then *<Name> was found dead.* The morning never reveals the victim's role.
2. **The Doctor saved them** — *Everyone opens their eyes.* plus *The Doctor saved a life tonight.* in `role-doctor`.
3. **The Mafia took nobody** — *Nobody died tonight.* / *The Mafia did not take anyone this round.* (never credit the Doctor here).

Kicker *DAWN · DAY n* in `phase-day`. Each player presses *Start the day*; the TV shows *Waiting for n players* instead of the button.
