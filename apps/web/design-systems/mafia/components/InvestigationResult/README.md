# InvestigationResult

What the Sheriff learns, popped in (`popIn` .4s) after an investigation.

- Frame and verdict text in `role-sheriff` for *clean*, `mafia-red` (`is-mafia`) for *is MAFIA*.
- Verdict in Tektur 900 32px uppercase; caption *INVESTIGATION RESULT*; the only action is *Close your eyes*.
- Only ever shown on the Sheriff's phone. The result stays available during the following day.
