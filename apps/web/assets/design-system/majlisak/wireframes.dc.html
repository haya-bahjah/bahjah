Every guest-facing screen carries the host's theme and event name (shown: Sara's graduation). Host advances everyone together; timer optional; green/red only on reveal; leaderboard only when scoring is on.
ENGLISH · LTR
SAME GAME, ANY OCCASION
The theme the host picks dresses every guest-facing screen: full-bleed art for waiting moments, a banner with the event name during play. Answer states and chrome stay neutral so the theme never fights the game.
