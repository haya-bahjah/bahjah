# Timer

A chunky ink-outlined progress bar with the seconds beside it.

- The track is `kyb-card2` with a 2px `kyb-ink` outline and pill ends, 16px tall. The fill is `kyb-green`.
- In the danger state, fill and count turn `kyb-pink`.
- **Note:** the game runs without a clock: every phase ends when the room has finished. The timer is kept in the system for rooms that use one and for the TV's legacy screens. Don't add one to a new phase.
