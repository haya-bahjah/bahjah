# PromptCard

The round's question on the TV, set in a wobbly gold card with a dashed inner rule and two doodle marks.

- 3px `kyb-yellow` frame with the `--kyb-r-lg` hand-drawn corner and a `shadow-hard-lg` offset. A 2px dashed yellow rule sits 9px inside at 55% opacity.
- Doodles: a pink ✕ off the top inline-start corner and a green dot off the bottom inline-end corner. They are decoration only (`pointer-events:none`).
- The question is set in the `prompt` style at weight 400. The face does the work.
- On phones the padding drops from 44×40 to 30×22.
