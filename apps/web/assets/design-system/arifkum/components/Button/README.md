# Button

Four buttons: the green CTA, a pink variant for the finale, the pixel end-room pill and the dashed move-on link.

| Class | Look | Use |
|---|---|---|
| `kyb-cta` | `kyb-green` fill, `kyb-on-accent` text, 8px radius, 16px uppercase with .14em tracking | The one move: *Start on Imagine if*, *Lock it in*, *Show the truth*, *Next round*. |
| `kyb-cta--pink` | `kyb-pink` | The finale: *Play again*. |
| `kyb-cta--ghost` | transparent, `kyb-line` | Secondary: *Share*. |
| `kyb-endbtn` | pixel 10px pill, ink-64 | *End room* in the host's header. Turns pink on hover. |
| `kyb-moveon` | dashed pill, 13px bold, ink-40 | The host's override when someone has walked away: *Move on without them*. |

- Hover lifts 2px with a matching glow. Disabled is 40% opacity.
- Labels name what happens next. Before a choice exists, the CTA says what is missing (*Pick a category first*).
