# Podium

The live standings: first place centred and tallest, second and third flanking it, everyone else as chips below.

- Plinth colours: 1st `kyb-yellow` (150 × 118, score 48px), 2nd `kyb-pink` (112 × 78), 3rd `kyb-green` (104 × 58). Corners are `18px 8px / 8px 18px` and text is `kyb-on-accent`.
- Faces are framed in the plinth colour. Only the leader gets a crown.
- 4th place down: `kyb-restchip` with a hand-drawn pill, 2px `kyb-line` border, place, name and score.
- The game-over screen deliberately doesn't use the podium. It shows only the winner (see FinalWinner).
