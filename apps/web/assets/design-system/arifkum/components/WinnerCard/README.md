# WinnerCard

Between rounds, one tilted card names the round's single winner. It shows no scores and no ranking.

- 4px frame in the winner's colour (yellow by default) with a matching glow, `--kyb-r-lg`, rotated -1°, popping in over 420ms.
- The character sits beside a pixel kicker (*★ ROUND WINNER*) and the name at 30–62px, weight 900. On phones they stack.
- Exactly one winner per round. Ties break on round score, then correct matches, then who locked their board first.
- Numbers are held back on purpose so the room doesn't start playing the leaderboard between rounds.
