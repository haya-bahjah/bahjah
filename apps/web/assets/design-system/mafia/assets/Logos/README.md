# Logos
- `mafia-logo.png` (720², RGBA): full logo, red Arabic wordmark over smoke and fedora silhouette. Dark grounds only.
- `mafia-mark.png` (224²): compact mark for small placements (game tiles, favicons).
- `logo-mark.svg`: single-ink vector mark drawn in currentColor; it renders black via `<img>`. Inline it and set `color` to `mafia-red` or `text-primary`.
- `mafia-lockup.webp` (490×205): horizontal lockup used on the landing hero.
