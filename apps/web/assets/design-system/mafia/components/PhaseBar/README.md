# PhaseBar

The title-and-clock line above the night and the day.

- Title in `phase-title` (Tektur 800, 19px, uppercase): *Night 2*, *Day 2*.
- Clock in `timer` pixel type inside a 6px-radius box, in the current phase colour, pushed to the inline end (mirrors in Arabic).
- The clock is the server's: it pauses when the host pauses, and shows the remaining time, not elapsed.
