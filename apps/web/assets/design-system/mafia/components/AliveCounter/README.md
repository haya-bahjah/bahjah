# AliveCounter

The headline of the header: how many players are still alive, out of how many sat down.

- The number in `alive-count` (Tektur 900), the table size in muted 13px directly after it — reads as "7/8", no spaces — then *ALIVE* in pixel type.
- Tone warms as the room empties: `alive-steady` (more than half alive) → `alive-warm` (past halfway) → `alive-hot` (the last few, heart pulses at 1.6s; off under reduced motion).
- Border, fill and glow are mixed from the tone so the whole chip changes colour together.
