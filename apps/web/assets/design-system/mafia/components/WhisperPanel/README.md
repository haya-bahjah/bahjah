# WhisperPanel

The Mafia's private channel during the night: the only group chat in the game.

- `rgba(20,8,10,.6)` ground with a 35% `mafia-red` border; header in pixel `mafia-red`; every avatar ring is `mafia-red`.
- Lines fade up (.3s). Speaker label 8px pixel, text 13px.
- A partner's suggestion line uses `whisper-red`.
- A five-player table deals a single Mafia: replace the sub-line with *You are working alone tonight* and hide the composer.
- Never rendered on the TV.
