# QuickReply

Pill-shaped canned lines a player can drop into the day discussion with one tap.

- Pill (`radius-pill`), 13px body text in `text-secondary`, `border-strong`.
- Hover/active: border and text go to `info-steel`.
- The four lines are fixed per language (`mafia-i18n.js` → `quick`). Keep them short, first person, and in the voice of someone defending themselves.
- Sits directly above the composer; wraps on phones.
