# ChatBubble

A message in the day discussion or a private thread.

- Others: `chat-other-fill`, hairline border, tail at the bottom inline-start (12/12/12/3 radius), speaker label above in 8px pixel.
- Mine: `chat-mine-fill` / `chat-mine-border`, tail at the bottom inline-end, no label.
- Max width 82%; words break rather than overflow.
- Day chat is anonymous by rule: the label is always *ANONYMOUS* (*Nobody can see who wrote what.*). Private threads show the partner's name.
